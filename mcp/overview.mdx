REalyse MCP connects AI assistants to REalyse data through the [Model Context Protocol](https://modelcontextprotocol.io) (MCP). Once it's connected, you can ask your assistant about the UK property market in plain English and it looks up the answer in REalyse.

You sign in with your existing REalyse account. There is no separate MCP login. For day-to-day use you don't paste tokens or API keys into the assistant. Scripts and unattended jobs can use a [team API key](/mcp/authentication#team-api-keys-for-scripts) instead.

Your questions stay in the assistant. REalyse records which tool ran. The log does not include the question text or the arguments sent with the call. REalyse does not receive the conversation text. Two people can ask similar questions and get different write-ups, because the assistant chooses the wording. [AI and your data](/mcp/ai-and-your-data) covers where that data is processed, how long it is kept, which subprocessors handle it, and how this sits with your subscription terms and the privacy policy.

## What you can ask about

Your assistant picks from 21 read-only tools. [Available tools](/mcp/tools) lists them. In practice they cover:

- Sold prices, asking prices and asking rents for individual properties. Achieved rents are monthly market series, not individual listings.
- Monthly market trends: price per square foot, asking and achieved rents, asking student rents, yields, transactions and days on market.
- Planning applications and pipeline totals for an area, including build-to-rent.
- HM Land Registry titles and ownership, including HMO, brownfield and green belt flags, plus land and commercial price-paid transactions.
- A satellite image of a title boundary.
- Energy Performance Certificates (EPCs).
- Demographics, crime and nearby amenities.
- Policy rates: Local Housing Allowance (BRMA/LHA), London Living Rent and the Community Infrastructure Levy.

HMO searches can include licence details when REalyse has them. A title can still match the HMO filter without a licence record. Distressed-asset data is not available.

[Data coverage](/mcp/data-coverage) lists Core datasets and filters that MCP does not expose.

## Example questions

- "What have two-bed flats sold for within a mile of Clapham Junction this year?"
- "Compare average rents for two-bed flats in Leeds and Manchester over the last three years."
- "Which build-to-rent schemes are in the pipeline in Bristol, and what is their total gross development value?"
- "Find HMO titles within five miles of Bristol and show who owns them."
- "What are typical EPC ratings for flats in Camden, and what is the Local Housing Allowance there?"
- "Give me a demographics and crime snapshot for SW1A."

## Supported assistants

REalyse MCP works with any MCP client that can call a remote server over Streamable HTTP and complete OAuth sign-in. Guides below cover Claude, ChatGPT, Microsoft Copilot Studio, Cursor and Visual Studio Code with GitHub Copilot. [Connect your assistant](/mcp/connect) has the server URL and the values each client needs. Menu layouts change, so that page links to each vendor's own documentation for the current screens.

## Before you start

MCP access has to be enabled on your REalyse account. If you aren't sure whether you have it, ask your REalyse account manager.

Each account has a monthly data allowance. The default is 10,000 rows per calendar month (UTC). [Usage limits](/mcp/usage-limits) explains how rows are counted.
